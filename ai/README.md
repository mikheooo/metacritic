# AI-Assisted Development Transcripts

This directory is designated for storing conversation transcripts and logs from the AI-assisted development sessions (e.g. Antigravity / Gemini / Claude conversations) as required by project submission guidelines.

## Guidelines

1. **Transcript Storage**:
   - Transcripts will be exported and stored here prior to the final project submission.
   - Logs include step-by-step reasoning, architectural planning, code changes, and verification transcripts.

2. **Security & Secrets**:
   - **DO NOT** commit secrets, API keys, credentials, or sensitive connection strings in this directory.
   - Ensure all `.env` values or private access tokens are sanitized before saving logs here.

3. **Format**:
   - Markdown summaries, exported JSON transcripts, or raw session logs with clear timestamps and task tags.
